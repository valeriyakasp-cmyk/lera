# BizFlow

אפליקציית ניהול כספים לעסק, בנויה ב-Expo (React Native) עם expo-router.
עברית ו-RTL מלא, פונט Heebo, מונוכרום עם מבטא בורדו יחיד.

## הרצה

```bash
npm install
npx expo start
```

סריקת ה-QR מהטרמינל עם אפליקציית **Expo Go** בטלפון תפתח את האפליקציה.
להרצה בדפדפן: `npm run web`.

## מבנה

```
app/                 מסכים (expo-router — הניתוב נגזר משמות הקבצים)
  (tabs)/            חמשת הטאבים: בית · לקוחות · הוצאות · השראה · קופות
  new.tsx            תפריט ה-＋ המרכזי
  *-new.tsx          מסכי הוספה מודאליים
  monthly.tsx        סיכום חודשי וחלוקה לקופות
src/
  theme.ts           צבעים, טיפוגרפיה, מרווחים
  types.ts           מודל הנתונים
  store.tsx          מצב האפליקציה + שמירה מקומית (AsyncStorage)
  finance.ts         חישובי צפי, נטו וקטגוריות
  components/        רכיבי UI משותפים
```

## מה מחושב לבד

- תאריך הצפי של כל חשבונית נגזר מתנאי התשלום של הלקוח (שוטף+N, 50/50, מותאם).
- קטגוריית הוצאה נקבעת אוטומטית לפי שם העסק; תיקון ידני נשמר ונלמד להבא.
- סימון "נקנה" ברשימת הקניות הופך את הפריט להוצאה עסקית.
- הנטו והחלוקה לקופות מחושבים מראש לקראת הסיכום החודשי.

## מצב הנתונים

הנתונים נשמרים מקומית במכשיר בלבד. בהרצה ראשונה נטענים נתוני דוגמה,
שניתן לאפס מתוך טאב "קופות".

## דרישות שטרם מומשו

חיבור בנק (בנקאות פתוחה), איסוף קבלות מהמייל, ו-OCR לחשבוניות —
כולם מוגדרים באפיון כשלב 2 ודורשים שירותי צד שלישי.
