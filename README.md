# המשימות שלי

אתר אישי לניהול משימות יומיות — משימות, תת־משימות, וסימון אוטומטי של משימה כ"הושלמה"
כשכל תת־המשימות שלה מסומנות. עיצוב מינימליסטי בעברית (RTL), והנתונים נשמרים בענן פרטי.

---

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה האתר |
| `assets/styles.css` | כל העיצוב (צבעים, ריווחים, טיפוגרפיה) |
| `assets/app.js` | הלוגיקה + הסנכרון לענן |
| `supabase/schema.sql` | הסקריפט שיוצר את הטבלה בענן |

אין תהליך build ואין תלויות להתקין — זה אתר סטטי רגיל.

---

## איך זה עובד

* **משימה ראשית** — מוסיפים בשורה העליונה, Enter כדי לשמור.
* **תת־משימות** — לוחצים על החץ בצד המשימה ומוסיפים בשורה שנפתחת.
* **השלמה אוטומטית** — ברגע שכל תת־המשימות מסומנות, המשימה הראשית מסומנת
  כהושלמה ועוברת לקטע "הושלמו" בתחתית העמוד.
* **סימון המשימה הראשית** מסמן את כל תת־המשימות שלה, ולהפך — ביטול סימון מנקה את כולן.
* **עריכה** — לוחצים על טקסט המשימה ומקלידים. Enter שומר, Esc מבטל.
* **קיצור מקלדת** — `n` מקפיץ את הסמן לשורת ההוספה.

### סטטוסים

בתפריט ⋯ שליד כל משימה אפשר לסמן **בעבודה** או **בהמתנה**. הסטטוס מופיע
כתגית צבעונית על המשימה. לחיצה חוזרת על אותו סטטוס מנקה אותו, וסימון
המשימה כהושלמה מנקה אותו אוטומטית.

### תאריכים ומעקב אחורה

כל משימה שייכת ליום. החיצים משני צדי התאריך מדלגים יום אחורה או קדימה,
ולחיצה על התאריך עצמו פותחת לוח שנה לקפיצה לכל יום. ככה אפשר לחזור אחורה
ולראות בדיוק מה הושלם ומה לא בכל יום — הכרטיסים שהושלמו יושבים בקטע
"הושלמו" והפתוחים למעלה.

### "לא הספקתי"

בתפריט ⋯ של כל משימה יש **לא הספקתי — העברה ליום אחר**:

* **העברה למחר** — היום שאחרי היום שבו המשימה יושבת.
* **העברה להיום** — מופיע כשמסתכלים על יום שעבר.
* **בחירת תאריך…** — לוח שנה לבחירת כל יום אחר.

המשימה עוברת ליום הנבחר עם כל תת־המשימות והסטטוס שלה, ומתווספת בסוף
הרשימה של אותו יום.

בנוסף, כשיש משימות פתוחות מימים קודמים מופיע באנר בראש היום עם כפתור
להעברת **כולן** להיום בלחיצה אחת.

הנתונים נשמרים תמיד גם מקומית בדפדפן, כך שהאתר עובד גם בלי אינטרנט
ומסתנכרן לענן ברגע שהחיבור חוזר.

## הקמת הענן (פעם אחת, ~5 דקות)

הנתונים נשמרים ב־**Supabase** — שירות חינמי שבו את מקימה מסד נתונים פרטי משלך.
אף אחד חוץ מהמשתמש שלך לא יכול לראות את המשימות.

### 1. פתיחת פרויקט

1. להיכנס ל־[supabase.com](https://supabase.com) וללחוץ **Start your project** (אפשר להירשם עם GitHub).
2. **New project** → לתת שם (למשל `tasks`), לבחור סיסמה למסד הנתונים ואזור קרוב (Frankfurt).
3. לחכות דקה־שתיים עד שהפרויקט עולה.

### 2. יצירת הטבלה

1. בתפריט הצדדי: **SQL Editor** → **New query**.
2. להעתיק את כל התוכן של הקובץ [`supabase/schema.sql`](supabase/schema.sql) ולהדביק.
3. ללחוץ **Run**. אמור להופיע `Success`.

> הקובץ בטוח להרצה חוזרת. אם כבר הקמת את הטבלה בעבר, פשוט הריצי אותו שוב
> כדי להשלים עמודות שנוספו מאז (למשל `status`) — הנתונים הקיימים נשמרים.

### 3. העתקת פרטי החיבור

בתפריט הצדדי: **Project Settings** → **API**. משם צריך שני דברים:

* **Project URL** — נראה כמו `https://abcdefgh.supabase.co`
* **anon public** key — מחרוזת ארוכה שמתחילה ב־`eyJ...`

> המפתח הזה מיועד לשימוש בדפדפן ואינו סוד — ההגנה על הנתונים נעשית
> דרך ה־Row Level Security שהוגדר ב־`schema.sql`, שמאפשר לכל משתמש
> לגשת אך ורק לשורות שלו.

### 4. חיבור האתר

1. לפתוח את האתר וללחוץ על גלגל השיניים בפינה.
2. להדביק את ה־URL ואת המפתח → **חיבור לפרויקט**.
3. להזין אימייל וסיסמה → **יצירת חשבון** (בפעם הראשונה).
4. אם מגיע מייל אישור — לאשר, ואז **כניסה**.

זהו. מכאן כל שינוי נשמר אוטומטית, ואפשר להיכנס מכל מכשיר עם אותו אימייל וסיסמה.

> **טיפ:** אם לא בא לך להתעסק עם אישור מייל, אפשר לכבות אותו:
> **Authentication** → **Sign In / Providers** → **Email** → לבטל את *Confirm email*.
>
> **מומלץ:** אחרי שיצרת את החשבון שלך, כדאי לסגור הרשמות חדשות —
> באותו מסך לבטל את *Allow new users to sign up*. ככה אף אחד אחר לא יכול להירשם לפרויקט.

## העלאת האתר לאוויר

הכי פשוט — GitHub Pages, חינם:

1. בריפו: **Settings** → **Pages**.
2. תחת *Build and deployment* → *Source*: לבחור **GitHub Actions**.

הוורקפלואו שנמצא ב־`.github/workflows/pages.yml` יעלה את האתר בכל דחיפה
לענף הראשי של הריפו, והכתובת תהיה `https://<שם-המשתמש>.github.io/lera/`.

לחלופין אפשר פשוט לפתוח את `index.html` מקומית בדפדפן — הכול עובד גם ככה.

### הוספה למסך הבית בנייד

בספארי/כרום בנייד: שיתוף → **הוספה למסך הבית**. האתר ייפתח כאפליקציה מלאה.

## עיצוב

הצבעים והריווחים מוגדרים כמשתני CSS בראש `assets/styles.css`:

```
--blue-700 #4E93D4   --page   #F5F5F7   --ink    #1A1A1A
--blue-500 #5FA3DE   --card   #EFEFF1   --ink-2  #6E6E73
--blue-200 #C9E3F8   --surface #FFFFFF  --ink-3  #A1A1A6
```

הריווחים בנויים על רשת של 8 פיקסלים (`--s1`…`--s8`) וסקאלת פינות מעוגלות
של 8/12/16/24/32 פיקסלים. לשינוי גוון או ריווח — מספיק לערוך את המשתנה בראש הקובץ.
